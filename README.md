# 🎓 PlacementIQ

An end-to-end machine learning-based student analytics system that predicts placement chances and provides actionable recommendations through an interactive web application.

---

## Features

- 📊 Predicts student placement probability using ML models  
- 📈 Provides confidence levels (High / Medium / Low)  
- 💡 Generates personalized improvement suggestions  
- 📉 Analyzes key factors like CGPA, internships, projects, and skills  
- 🌐 Interactive UI built using Streamlit  

---

## How It Works

1. User inputs student details (CGPA, aptitude, internships, etc.)
2. Data is preprocessed using trained preprocessing pipeline
3. Model predicts placement probability
4. System generates personalized suggestions based on weak areas

---

## Tech Stack

- Python  
- Pandas, NumPy  
- Scikit-learn  
- Streamlit  
- Joblib  

---

## Run Locally

pip install -r requirements.txt
streamlit run app.py

---

## Key Highlight

This project goes beyond prediction by providing a recommendation system that suggests actionable improvements such as enhancing aptitude, gaining internships, and building projects based on model insights.
